# Standard Test Suite 01: RISC-V International Architecture Tests (`riscv-arch-test`)

This directory contains the official **RISC-V International Architecture Test Suite** configured to verify the **CPU Core Only** (`riscv_cpu.v`) against the golden reference simulator (**Spike ISS**).

---

## 1. Standard Suite Overview

- **Origin**: RISC-V International Architecture Test Special Interest Group (formerly known as `riscv-compliance`).
- **Standard Purpose**: The definitive compliance suite required by RISC-V International for any processor core implementation claiming RV32I / Privileged / Zicsr conformance.
- **Verification Method (Signature Comparison)**:
  1. The test executes a deterministic sequence of instructions targeting boundary conditions, corner values, and corner sign-extensions.
  2. The test program deposits critical intermediate values into a contiguous signature memory buffer bounded between `begin_signature` and `end_signature`.
  3. The CPU core writes a completion signal to `tohost`.
  4. The testbench automatically extracts the memory signature and compares it byte-for-byte against the golden signature generated by **Spike ISS** (`spike --isa=rv32i_zicsr`).
  5. If every single 32-bit signature word matches Spike identically, the test passes.

---

## 2. Core-Only Testbench Architecture

In this test environment, the CPU core is tested in complete isolation from the uncore/SoC fabric:
- **DUT**: [riscv_cpu.v](file:///home/ganesh/Desktop/riscv/riscv_pipelined_quartus/main/riscv_cpu.v) (5-stage pipelined RV32I core).
- **Interconnect**: Direct connection from the core's unified AHB-Lite Master (`HADDR, HWDATA, HTRANS, HRDATA, HREADY`) to a single-cycle synchronous [ahb_ram.v](file:///home/ganesh/Desktop/riscv/riscv_pipelined_quartus/main/ahb_ram.v).
- **Excluded**: Uncore peripherals, APB bridge, UART, GPIO, PLIC, CLINT, and FT1248 debugger. Zero uncore contention or peripheral wait-state interference.

## 3. Test Coverage

| Group Target | Included Tests | Scope of Verification |
|---|---|---|
| `test_alu` | `add-01`, `addi-01`, `and-01`, `andi-01`, `or-01`, `ori-01`, `xor-01`, `xori-01`, `sll-01`, `slli-01`, `srl-01`, `srli-01`, `sra-01`, `srai-01`, `slt-01`, `slti-01`, `sltu-01`, `sltiu-01`, `sub-01`, `lui-01`, `auipc-01` | Arithmetic, logical, bitwise shifts, comparisons, signed/unsigned bounds, upper immediate generation. |
| `test_branch` | `beq-01`, `bne-01`, `blt-01`, `bge-01`, `bltu-01`, `bgeu-01`, `jal-01`, `jalr-01` | Conditional branches, target PC computation, pipeline flushing, register linking (`rd = PC + 4`). |
| `test_memory` | `lw-align-01`, `lh-align-01`, `lhu-align-01`, `lb-align-01`, `lbu-align-01`, `sw-align-01`, `sh-align-01`, `sb-align-01` | Byte and halfword subword access, byte strobes, sign extension, zero extension, load-use hazard handling. |
| `test_priv` | `ecall`, `ebreak` | Synchronous environment call and breakpoint exceptions, trap vectors, `mstatus`, `mepc`, `mcause`. |
| `test_zicsr` | `Zicsr-csrrw-00`, `Zicsr-csrrs-00`, `Zicsr-csrrc-00`, `Zicsr-csrrwi-00`, `Zicsr-csrrsi-00`, `Zicsr-csrrci-00` | Atomic read-and-set, read-and-clear, read-and-write for all Control and Status Registers (CSRs). |

---

## 4. How to Run

From this directory:

```bash
# Run all architectural compliance tests
make test_all

# Run individual instruction categories
make test_alu
make test_branch
make test_memory
make test_priv
make test_zicsr

# Clean build and signature artifacts
make clean
```
