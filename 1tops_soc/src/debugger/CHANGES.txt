2. KEY MODIFICATIONS & CUSTOMIZATIONS FROM ORIGINAL SOCDEBUG_TECH
--------------------------------------------------------------------------------
a) Hardware Core Halt & Resume Support:
   - In the original NanoSoC design, debug signals like EDBGRQ and DBGRESTART
     were tied to ground, and GPO8 only provided system reset.
   - In this adapted version, GPO8 bit 1 is explicitly mapped to 'core_halt_o'.
   - 'core_halt_o' connects directly to the 'ExternalStall' port of CORE-V Wally's
     hazard unit (hazard.sv).
   - Asserting 'core_halt_o' freezes all 5 pipeline stages (Fetch, Decode,
     Execute, Memory, Writeback) in place without flushing.
   - Deasserting 'core_halt_o' resumes execution from the exact instruction cycle.

b) Direct UART Transceiver Integration (socdebug_uart.v):
   - Bridges physical serial pins (uart_rx, uart_tx) directly to the ADP byte
     stream (COMRX/COMTX).
   - Configurable CLK_FREQ and BAUD_RATE (default: 50 MHz, 115200 baud).

c) Dedicated 2-Master AHB-Lite Bus Arbiter/Mux (ahb_mux.sv):
   - Connects Master 0 (RISC-V CPU Core) and Master 1 (Debugger).
   - When core_halt is active (or when Core is IDLE), the Debugger receives
     full bus mastership to read/write memory and accelerator spaces.
   - Properly handles 2-phase AHB pipelining (address phase and data phase).

d) Dedicated Accelerator Memory Space (0x30000000 - 0x30FFFFFF):
   - Defined in accelerator_debug_def.vh.
   - Allocated a full 16 Megabyte address space for the upcoming larger accelerator
     (CSRs, Input Activations, Weight Memory, Output Buffers), while maintaining
     backward compatibility with the current dummy multiplier.

3. SIGNAL CONNECTION GUIDE FOR wallypipelinedsoc.sv
--------------------------------------------------------------------------------
When you are ready to instantiate the debugger inside wallypipelinedsoc.sv,
connect the ports as follows:

1) Instantiate riscv_debugger_top:
   wire dbg_core_halt;
   wire [31:0] dbg_haddr, dbg_hwdata, dbg_hrdata;
   wire [1:0]  dbg_htrans;
   wire [2:0]  dbg_hsize, dbg_hburst;
   wire [3:0]  dbg_hprot;
   wire        dbg_hwrite, dbg_hmastlock, dbg_hready, dbg_hresp;

   riscv_debugger_top #(
       .CLK_FREQ    (50_000_000),
       .BAUD_RATE   (115200),
       .PROMPT_CHAR ("]")
   ) u_debugger (
       .clk             (HCLK),
       .rst_n           (HRESETn),
       .uart_rx         (DEBUG_UART_RX_PIN), // From external pin or USB-UART
       .uart_tx         (DEBUG_UART_TX_PIN), // To external pin or USB-UART
       .core_halt_o     (dbg_core_halt),
       .core_reset_o    (),
       .core_halted_i   (dbg_core_halt),
       .DEBUG_HADDR     (dbg_haddr),
       .DEBUG_HBURST    (dbg_hburst),
       .DEBUG_HMASTLOCK (dbg_hmastlock),
       .DEBUG_HPROT     (dbg_hprot),
       .DEBUG_HSIZE     (dbg_hsize),
       .DEBUG_HTRANS    (dbg_htrans),
       .DEBUG_HWDATA    (dbg_hwdata),
       .DEBUG_HWRITE    (dbg_hwrite),
       .DEBUG_HRDATA    (dbg_hrdata),
       .DEBUG_HREADY    (dbg_hready),
       .DEBUG_HRESP     (dbg_hresp),
       .GPO8            (),
       .GPI8            (8'h00)
   );

2) Connect Halt to RISC-V Core:
   Connect 'dbg_core_halt' to the .ExternalStall port of 'core':
   .ExternalStall (dbg_core_halt)

3) Connect AHB Bus Mux (ahb_mux.sv):
   Insert ahb_mux between the core AHB master and the uncore/accelerator bus:
   ahb_mux #(
       .ADDR_WIDTH (32),
       .DATA_WIDTH (32)
   ) u_ahb_mux (
       .HCLK         (HCLK),
       .HRESETn      (HRESETn),
       .core_halt    (dbg_core_halt),

       // M0: CPU Core AHB outputs from core
       .M0_HADDR     (core_haddr),
       .M0_HWDATA    (core_hwdata),
       .M0_HWRITE    (core_hwrite),
       .M0_HTRANS    (core_htrans),
       .M0_HSIZE     (core_hsize),
       .M0_HBURST    (core_hburst),
       .M0_HPROT     (core_hprot),
       .M0_HMASTLOCK (core_hmastlock),
       .M0_HRDATA    (core_hrdata),
       .M0_HREADY    (core_hready),
       .M0_HRESP     (core_hresp),

       // M1: Debugger AHB
       .M1_HADDR     (dbg_haddr),
       .M1_HWDATA    (dbg_hwdata),
       .M1_HWRITE    (dbg_hwrite),
       .M1_HTRANS    (dbg_htrans),
       .M1_HSIZE     (dbg_hsize),
       .M1_HBURST    (dbg_hburst),
       .M1_HPROT     (dbg_hprot),
       .M1_HMASTLOCK (dbg_hmastlock),
       .M1_HRDATA    (dbg_hrdata),
       .M1_HREADY    (dbg_hready),
       .M1_HRESP     (dbg_hresp),

       // Downstream Slave Bus to uncore & accelerator
       .S_HADDR      (HADDR),
       .S_HWDATA     (HWDATA),
       .S_HWRITE     (HWRITE),
       .S_HTRANS     (HTRANS),
       .S_HSIZE      (HSIZE),
       .S_HBURST     (HBURST),
       .S_HPROT      (HPROT),
       .S_HMASTLOCK  (HMASTLOCK),
       .S_HRDATA     (HRDATA),
       .S_HREADY     (HREADY),
       .S_HRESP      (HRESP)
   );

4. ACCELERATOR MEMORY MAP (0x30000000 - 0x30FFFFFF)
--------------------------------------------------------------------------------
The accelerator region corresponds to EXT_MEM_BASE (0x30000000) and
EXT_MEM_RANGE (0x00FFFFFF).

A. Current Dummy Multiplier (multiplier_ahb.sv):
   - 0x30000000 : Operand A (32-bit R/W)
   - 0x30000004 : Operand B (32-bit R/W)
   - 0x30000008 : Product Result (32-bit Read-Only)
   - 0x3000000C : Console Write Char (8-bit Write-Only)

B. Subdivided Space for Upcoming Larger Accelerator (e.g. 1TOPS / CTM):
   - 0x30000000 - 0x30000FFF (4 KB) : Control & Status Registers (CSRs)
       0x30000000: Control Register (Start, Abort, Soft Reset, IRQ Enable)
       0x30000004: Status Register (Busy, Done, Error, Status flags)
       0x30000008: Config Register (Model mode, Batch size, Precision)
       0x3000000C: Performance Counters (Cycle count)
   - 0x30001000 - 0x300FFFFF (~1 MB) : Input Data / Feature Activations Buffer
   - 0x30100000 - 0x307FFFFF (~7 MB) : Model Weights / Hypervectors / Clause Memory
   - 0x30800000 - 0x30FFFFFF (~8 MB) : Output Predictions / Classification Buffer

5. DEBUGGER PROTOCOL & COMMAND REFERENCE
--------------------------------------------------------------------------------
The debugger uses standard ASCII Debug Protocol (ADP) over UART:

- Halt Core:
    Send: C 0202<ENTER>
    Sets bit 1 of GPO8 -> ExternalStall = 1 -> Pipeline frozen.

- Resume Core:
    Send: C 0102<ENTER>
    Clears bit 1 of GPO8 -> ExternalStall = 0 -> Pipeline resumes.

- Set Memory Address:
    Send: A <hex_addr><ENTER>   (e.g. A 30000008)

- Read Memory / Register:
    Send: R<ENTER>
    Performs AHB bus read at current address and prints 32-bit hex value.

- Write Memory / Register:
    Send: W <hex_data><ENTER>   (e.g. W 00000010)

- Reset Core:
    Send: C 0201<ENTER> (assert reset)
    Send: C 0101<ENTER> (deassert reset)

6. PYTHON HOST TOOL (sw/dbg_cli.py)
--------------------------------------------------------------------------------
Usage examples:
  python3 dbg_cli.py -d /dev/ttyUSB0 halt
  python3 dbg_cli.py -d /dev/ttyUSB0 read 0x30000008
  python3 dbg_cli.py -d /dev/ttyUSB0 write 0x30000000 0x00000007
  python3 dbg_cli.py -d /dev/ttyUSB0 read_accel
  python3 dbg_cli.py -d /dev/ttyUSB0 resume
