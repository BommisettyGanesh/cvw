# Subsystem 06: Hardware Debugger Subsystem & Microarchitectural Features

This subsystem provides deterministic signal-level and protocol-level verification testbenches for the SoCDebug Hardware Debugger Subsystem, the ADP protocol engine, and the 3 CPU microarchitectural features.

---

## 1. Subsystem Architecture Overview

The Debugger Subsystem provides non-intrusive runtime inspection, hardware single-stepping, and memory upload/download capabilities over serial and high-speed interfaces.

```
       Hardware Pin 'dbg_sel'
                 │
      ┌──────────┴──────────┐
      │ (0) UART  │ (1) FT1248 
      ▼           ▼
 ┌──────────┐ ┌──────────┐
 │ UART     │ │ FT1248   │
 │ Receiver │ │ Streamer │
 └────┬─────┘ └────┬─────┘
      └─────┬──────┘
            ▼
 ┌──────────────────────┐      ┌─────────────────────────┐
 │ ADP Command Engine   │◄────►│ Core Step Controller    │
 │ (socdebug_adp_ctrl)  │      │ - ExternalStall (freeze)│
 └──────────┬───────────┘      │ - InstrRetired (pulse)  │
            │                  │ - dbg_core_reset        │
            ▼                  └────────────┬────────────┘
 ┌──────────────────────┐                   │
 │ AHB Debug Master     │                   ▼
 │ (socdebug_ahb)       │      ┌─────────────────────────┐
 └──────────┬───────────┘      │ 5-Stage Pipelined CPU   │
            │                  │ (riscv_cpu + hazard.v)  │
            ▼                  └─────────────────────────┘
 ┌──────────────────────┐
 │ 2-Master AHB Arbiter │
 │ (ahb_mux.sv)         │
 └──────────────────────┘
```

### Microarchitectural Hardware Features Integrated:
1. **`ExternalStall`**: Input to CPU Core and Hazard Unit (`hazard.v`). Holds all 5 pipeline stages (`StallF`, `StallD`, `StallE`, `StallM`, `StallW`) statically frozen in place while keeping clock running.
2. **`InstrRetired`**: 1-cycle active-high pulse generated by the Writeback stage when a valid instruction commits (excludes pipeline bubbles and stalls). Used by the step controller to halt execution after exactly one instruction.
3. **`dbg_core_reset`**: Dedicated core-only reset line (`core_HRESETn = HRESETn & ~dbg_core_reset`) allowing the debugger to reset CPU registers, pipeline registers, and PC back to `0x8000_0000` while preserving SRAM and peripheral states.

## 2. Test Suite Details

### A. Debugger Microarchitectural Features (`tb/tb_debugger_features.sv`)
- **TEST 1 (Power-on Reset)**: Verifies that global reset deasserts `core_HRESETn` and starts execution.
- **TEST 2 (ExternalStall 5-Stage Freeze)**: Asserts `ExternalStall` and verifies that all hazard unit stalls assert (`StallF..StallW = 1`) and the Program Counter remains frozen for 10 cycles.
- **TEST 3 (InstrRetired 1-Cycle Pulse & Single-Stepping)**: Programs the step controller for single-instruction stepping. Deasserts stall, verifies that exactly 1 instruction retires via `InstrRetired`, and verifies the core re-freezes on the next instruction.
- **TEST 4 (Multi-Step Execution)**: Advances execution through multiple sequential instructions, verifying arithmetic and register writeback.
- **TEST 5 (Core-Only Reset)**: Writes a signature (`0xDEADBEEF`) into Uncore DRAM, asserts `dbg_core_reset = 1`, and verifies that the CPU PC returns to `0x8000_0000` while DRAM contents remain intact.

### B. SoCDebug ADP Protocol & Bus Multiplexer (`tb/tb_debugger.sv`)
- **Protocol Multiplexing**: Tests hardware pin `dbg_sel` switching between UART and FT1248 high-speed streaming. Verifies complete protocol isolation (ignoring inactive interface).
- **Core Run Control**:
  - `C 0202`: Core Halt
  - `C 0102`: Core Resume
  - `C`: Status query (Halted, Running)
- **Memory Operations**:
  - `A <addr>`: Set address pointer
  - `W <data>`: Single word write
  - `R`: Single word read
  - `F <addr> <len> <pattern>`: Bulk memory fill
  - `U <addr> <len> <bytes>`: Raw binary stream upload
- **Hardware Polling**:
  - `P <addr> <mask` / `M <match>` / `V <val>`: Autonomous register polling with timeout and match detection.
- **Error Handling**:
  - `!`: AHB bus error response (`HRESP = 1`) on unmapped addresses.
  - `?`: Invalid command rejection.

## 3. How to Run

From this directory:

```bash
# Run all debugger subsystem tests
make test_all

# Run individual tests
make test_features
make test_adp_protocol

# Clean build artifacts
make clean
```

All test runs compile libraries fresh (`rm -rf work && vlib work && vlog ...`) before simulation.
